# ClaudeScope v0.1.1

This release sharpens the new Usage Intelligence experience on macOS.

## Highlights

- Added state-aware Usage Intelligence styling with clearer visual emphasis
- Improved summary and suggestion cards so they no longer repeat the same message
- Fixed highlighting so important phrases are emphasized correctly without breaking values like `20%`
- Polished Chinese copy to be shorter and easier to scan
- Updated the English and Chinese README feature descriptions

## Included in this release

- Usage Intelligence cards now adapt more clearly to risk, action, and opportunity states
- Titles, backgrounds, borders, and accent bars all reflect the current state
- Summary cards focus on status; suggestion cards focus on what to do next
- Highlighting now emphasizes key information instead of only numeric fragments
