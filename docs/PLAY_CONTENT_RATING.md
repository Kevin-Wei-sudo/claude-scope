# Google Play — IARC content rating

Pre-answered IARC (International Age Rating Coalition) questionnaire for
ClaudeScope. The expected outcome across all regions is **"Everyone"** /
"3+" / "everyone" depending on jurisdiction.

## Category

> **Utility, Productivity, Communication, or Other**

## Questions

| Question | Answer |
|----------|--------|
| Does the app contain violence? | No |
| Does the app contain sexually explicit content? | No |
| Does the app contain controlled substances (drugs/alcohol/tobacco)? | No |
| Does the app facilitate gambling or simulated gambling? | No |
| Does the app contain crude humor? | No |
| Does the app contain references to discrimination, hate speech, etc.? | No |
| Does the app share user-generated content with other users? | No |
| Does the app share user location with other users? | No |
| Does the app allow users to interact or exchange content? | No |
| Does the app share personal information with third parties? | No (only with Anthropic, which is the user's chosen account provider — disclose this anyway) |
| Does the app enable digital purchases? | No |
| Does the app contain ads? | No |

## Result

Submitting these answers should produce these labels:

- **ESRB**: Everyone
- **PEGI**: 3
- **USK**: 0
- **ACB**: G
- **GRAC**: All
- **IARC Generic**: 3+
