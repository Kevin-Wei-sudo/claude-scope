ClaudeScope 帮你实时看清 Claude API 用量，再也不用担心任务进行到一半触发限流。OAuth 登录后，5 小时和 7 天窗口的实时百分比直接呈现在首页和桌面。

功能

• 今日概览——一眼看到本周额度还剩多少
• 5 小时 / 7 天窗口——并排进度，实时倒计时到下次重置
• 模型占比——本周 Sonnet vs Opus 的消耗分布
• 趋势预览——最近 7 天的紧凑柱状图
• 历史页——7 天 / 30 天 / 90 天切换，展示峰值、模型占比和最近快照
• 桌面小组件——小、中、大三种尺寸，点击即可回到 App
• 阈值通知——自定义 50%-100% 之间任意阈值，超出即推送
• 后台轮询——15 分钟 / 30 分钟 / 1 小时 / 3 小时可选
• 中英双语

隐私

• OAuth 令牌本地加密存储（Android Keystore）
• 用量历史不离开你的设备
• 用量 API 只与 Anthropic 通信（api.anthropic.com / platform.claude.com）
• 安装归因和匿名的 App 内事件统计通过 AppsFlyer 与 Meta（Facebook）SDK 完成——不包含个人信息、不包含登录数据。你可在系统设置里重置或停用 Android 广告 ID 以选择退出。
• 详细项目请查看隐私政策

要求

• Android 8.0（API 26）及以上
• Claude 账户

ClaudeScope 是一款独立的第三方伴随应用，与 Anthropic 无关联。
